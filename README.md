# 查字宝

给孩子使用的 iPad 查字页面，支持语音、汉字和拼音查找，以及读音、组词、部首和笔顺。

正式入口：<https://hanzi.usfan.net/char-dict.html>

## 当前语音方式

- 识别通过同源 `/api/asr` 调用现有语音服务，需要联网。
- 朗读通过 `/api/tts` 获取音频，服务器磁盘、浏览器和页面内存共同缓存已用读音。
- 点击后立即显示等待状态，新点击和页面返回会取消旧播放。
- 服务失败会明确提示，不再自动下载大型本地语音模型，也不后台下载整套字典读音。
- 已缓存的读音可以复用；不要把缓存可用等同于所有功能完全离线可用。

## 英文课本取词

孩子可以拍课本或从相册选照片。英文识别在浏览器本机完成，点选照片里的词后显示发音、简短中文解释和一条中英例句；也保留手动输入和语音入口。照片不会上传，只有选中的词会查询现有英文接口。相机菜单、真实课本照片质量和实体 iPad Safari 仍需实机验证。

英文例句使用现有 `/api/tts?lang=en`。服务器默认先用 Edge TTS；如果 Edge 失败且已配置 `AZURE_SPEECH_KEY` 与 `AZURE_SPEECH_REGION`，英文会用 Azure 兜底。

## 粤语读法

页面在拼音下面显示每个字的粤语读法（粤拼）。数据是构建期生成的静态文件
`models/dictionary/cantonese-data.js`，取数与判读运行时不联网。词表里的读法按“实际读音”
口径给出；只靠单字判断不出来的多读字会标“多读”，不假装确定。

粤语发音走 `/api/tts?lang=yue`，服务器把页面算出的粤拼逐字交给 Azure 官方语音
（`alphabet="sapi"`），所以念什么由我们的字表决定，不由引擎猜。免费通道的 edge-tts
不支持音素注入，母语音者实测 12 个词错 3 个（声调滑移），已弃用。服务器需要
`AZURE_SPEECH_KEY` 与 `AZURE_SPEECH_REGION` 两个环境变量；缺配置时粤语朗读直接报错，
不会静默退回普通话。播放入口有三处：字头页单字、组词整词、整句（含中英混合句里
的中文部分）。

## 字库和笔顺

页面保留原有字条目，补充数据放在 `models/dictionary/`。数据来源、版本、许可和生成步骤见该目录的 `sources.md`。

笔顺只显示真实路径。没有路径的字明确显示缺失状态，不按估计笔画数生成假笔顺。

横屏内容按实际高度排列，空间不足时可以纵向滚动。候选保留识别原句与全部候选字，现有组词帮助分辨同音字。

## 本地验证

```sh
python3 .github/scripts/serve-preview.py 8765
```

打开 <http://127.0.0.1:8765/char-dict.html>。此服务读取本地页面并代理真实线上语音接口，语音请求会发往正式服务。它仅监听本机地址。

旧的本地 `dev-server.py` 含固定识别结果和假音频，不能用于语音质量、延迟或发布验收。

```sh
node .github/scripts/check-client.mjs
node .github/scripts/check-dictionary.mjs
```

检查覆盖页面脚本语法、音频采样率转换和字库完整性。真实儿童发音准确率与实体 iPad Safari 的表现仍需在实际设备上验证。

## 发布

推送前执行 `doc/deploy.md` 的检查。现有 GitHub Actions 将 `deploy` 分支部署到宝塔站点；其他功能分支先通过 PR 合并到 `deploy`。语音供应商和服务器配置不由本次页面优化改变。

发布后核对工作流对应提交、线上文件哈希、真实音频响应和页面操作，不能仅凭健康接口判断完整体验通过。
